# dsh plugins

This repository is an npm monorepo for DSH plugins.

Plugin packages live under `packages/`. Build, test, or typecheck every package from the repository root:

```sh
npm run build
npm test
npm run typecheck
```

Current packages:

- `packages/dsh-code-deep`
- `packages/dsh-native-agents`
- `packages/dsh-skill-hub`
